(02) The point

A smaller, calmer UI foundation

Keep the server-rendered web beautiful.

01 / macros

Jinja-native by design

Import a macro, pass your data, ship HTML. Components fit the templating workflow your Flask app already has.

02 / output

Tailwind without the ceremony

Use Tailwind CSS v4 to build your output stylesheet. Jinjalume stays responsible for markup and accessible states.

03 / growth

Progressive enhancement

Start with semantic HTML. Add native browser APIs, HTMX, or Alpine when the interaction earns it.

(03) Make it better
